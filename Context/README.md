# Contexto público del portafolio

Edición aprobada: GEP-008 · DEVGEP+ V9. Publicación autorizada mediante la misión GEP-009.

Arquitectura: HTML/CSS/JavaScript estático. Se preservan automatización diaria de contribuciones, doce proyectos, veintitrés credenciales y diecinueve tecnologías. Los recursos de diseño demostrativo se identifican como tales; las copias públicas tienen saneamiento de privacidad.

GitHub Pages publica main desde la raíz. El trabajo privado, respaldos y originales se excluyen mediante lista explícita y reglas de ignorado. Las fuentes de otros proyectos no son necesarias para ejecutar el sitio.

Estado y límites de verificación: [boletín GEP-009](../docs/PORTAFOLIO-GEP-009.md). Los cambios posteriores requieren su alcance y verificación correspondientes.
