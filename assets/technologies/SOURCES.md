# Logos del cintillo · GEP-008

Uso identificativo de tecnologías del perfil, sin patrocinio ni afiliación. Los archivos se sirven localmente como imágenes; no se cargan librerías ni CDNs de iconos.

- 16 variantes `original` de [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons), licencia de distribución [MIT](https://github.com/devicons/devicon/blob/v2.17.0/LICENSE). Copyright (c) 2015 konpa. Texto completo conservado en `DEVICON-LICENSE.txt`.
- Power BI: [SVG Logos, revisión b9edc65](https://github.com/gilbarbara/logos/blob/b9edc65f8946027cb5e2fe6c772e914cf3649fba/logos/microsoft-power-bi.svg), distribución [CC0-1.0](https://github.com/gilbarbara/logos/blob/b9edc65f8946027cb5e2fe6c772e914cf3649fba/LICENSE.txt). Texto en `SVG-LOGOS-LICENSE.txt`.
- Render: [Simple Icons, revisión c37b20d](https://github.com/simple-icons/simple-icons/blob/c37b20d397a710fdd402aae3cb643b820b142074/icons/render.svg), distribución [CC0-1.0](https://github.com/simple-icons/simple-icons/blob/c37b20d397a710fdd402aae3cb643b820b142074/LICENSE.md). Texto en `SIMPLE-ICONS-LICENSE.txt`.
- SQL: recurso tipográfico propio. No se acreditó un logotipo universal de marca para el lenguaje; no se sustituye por la marca de un proveedor de base de datos.

Los 18 archivos de terceros se conservan byte por byte, con sus proporciones y colores. Las formas geométricas intrínsecas de algunas marcas (por ejemplo, JavaScript, TypeScript o .NET) pertenecen al dibujo original: no son tarjetas o fondos añadidos por el portafolio.

Las licencias de distribución de las colecciones no conceden derechos de marca ni implican aprobación de sus titulares. No se afirma que las colecciones sean canales oficiales de cada fabricante. Se emplean representaciones reconocibles de sus marcas, sin redibujarlas ni deformarlas.

Procedencia por archivo, revisión, SHA-256 y criterio de SQL: `docs/technology-icons.json` desde la raíz del repositorio. El preparador solo descarga cuando se invoca expresamente; el sitio no necesita red para estos logos.
